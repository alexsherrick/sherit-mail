# Contributing

Bug reports and ideas are welcome as issues.

Code is a different matter. Sherit is licensed under the AGPL-3.0, and Sherit Labs also licenses it commercially. A commercial
licence can only be granted for code Sherit Labs holds the rights to, so a change from outside can be merged only once its author
has signed a contributor licence agreement letting Sherit Labs license that change on both terms. The agreement is not published
yet. Until it is, please open an issue describing the change instead of a pull request.
